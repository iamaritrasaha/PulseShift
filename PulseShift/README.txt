PulseShift - native Windows Arduino project

Open PulseShift.ino in Arduino IDE 2.3.10.
Board: ESP32 Dev Module, Espressif ESP32 core 2.0.17.
Settings: UserConfig.h; defaults preserve the six-LED synthetic demo.
Serial: 115200 baud. No BLE implementation is present.

See ../README-Windows.md for pinned libraries, reproducible native builds,
simulation, upload instructions and hardware checks still pending.
Use ../Open-Arduino.ps1 to keep IDE user data and temporary files on D:.
The original WSL instructions are preserved in README-original-WSL.txt.
